# 🏔️ 尼泊尔喜马拉雅泥石流 3D 动力学仿真系统 (Nepal Debris Flow Simulation 3D)

基于 **Three.js** 与 **WebGL** 构建的高保真 3D 动态地质灾害推演仿真系统。聚焦喜马拉雅高位落差、高流速、强铲刮增容及谷底堰塞成湖的全过程链式演化。

---

## 🌟 核心功能与亮点

1. **三阶段完整灾害链动力学推演**：
   - **Phase 01：暴雨软化与高位滑坡起动**（5,120m 高海拔冰碛坡体失稳崩塌）。
   - **Phase 02：冲沟高速下泄与强烈铲刮增容**（峰值流速达 48.5 m/s，体积剧增至 420 万 m³）。
   - **Phase 03：谷底漫溢冲击与堰塞成湖**（下游村落与主公路桥梁被毁，主河道阻断形成高危堰塞湖）。

2. **程序化三维场景构建（零外部模型依赖）**：
   - **高海拔峡谷地形**：程序化高程生成，雪线、岩壁、深切冲沟、林线与河漫滩分层着色。
   - **多相动力学流体粒子系统**：粘稠泥浆条带、300+ 碰撞翻滚大块石、12,000+ 高速飞溅泥雾粒子与冲积扇/坝体动态隆起。
   - **基础设施与破坏物理**：沿河村落石砌藏式民居、跨河钢桁架主桥，在泥石流冲击下发生倾斜、断裂与掩埋。
   - **季风暴雨与高空大气**：8,000+ 雨滴粒子、深谷低空流云浮雾、动态闪电与光照增强。

3. **科研级 HUD 遥测与交互控制台**：
   - **实时遥测仪表盘**：瞬时前锋流速、高程落差、动水冲击压强、降雨强度与铲刮增容体积监控。
   - **2D 动态沿程高程剖面图**：Canvas 实时绘制纵坡降与前锋位置指示。
   - **多机位智能切换**：宏观鸟瞰、浪头跟随（带流速镜头震颤）、崩塌源区、村落冲击、峡谷横切与自由漫游。
   - **交互控制坞**：时间轴拖拽跳跃、阶段直达、0.5x~2.0x 倍速调节、全屏切换与程序化 Web Audio 音效。

## 🚀 快速启动

在终端运行以下命令：

```bash
cd /home/dannyaw/nepal-debris-flow-simulation
bash start.sh
```

打开终端输出的链接（例如 `http://localhost:8090`）即可直接在浏览器中运行。
